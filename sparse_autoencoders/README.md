# Sparse Autoencoders

Top-k SAEs (8x expansion, k=32) are trained on the MLP output and the residual stream at each of the 8 layers of `openai/circuit-sparsity`. They are used to check whether the structure found by variance partitioning also shows up in an independently learned feature basis.

All paths in `config.json` resolve relative to this folder.

## Steps

```bash
python prepare_data.py          # data/constructor_stubs.parquet from the VP prompt set
python training/retrain.py      # harvest activations and train SAEs -> data/saes/
python pipeline.py              # feature discovery + path attribution -> data/reports/
python factorial_specificity.py # AST vs. builtin specificity of winner features
python post_hoc_analyses.py     # density, polysemy, effective rank, staged ablation
```

The factorial study in `study_v2/` is described in [`study_v2/STUDY_DESIGN.md`](study_v2/STUDY_DESIGN.md). Its external-replication step also needs the older 8,897-prompt set as `data/contrastive_stubs.parquet`. The prompts ship in `data/study_v2/cache/metadata_old.parquet`; copy that file to `data/contrastive_stubs.parquet` before running `study_v2/harvest_all.py`.

## Included results

Small JSON outputs from the runs used in the report are kept under `data/posthoc/`, `data/study_v2/reports/` and `data/analysis_output/`. Activation caches and SAE weights are regenerated by the steps above.
